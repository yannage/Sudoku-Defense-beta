# Sudoku Defense audio

All WAV files in this directory are original procedural compositions created for this project. They use sine-wave harmonics, soft amplitude envelopes, and seeded noise; no third-party recordings, samples, or music are included.

Format: mono, 22,050 Hz, signed 16-bit PCM. `garden_loop.wav` is an eight-second seamless ambient loop. The remaining files are one-shot effects. `scripts/sound.gd` applies the final mix, pitch variation, voice limits, and rate limits.
