# Sudoku Defense Godot integration
Godot 4.7.x, GDScript, Compatibility renderer. Native Node3D world and CanvasLayer UI. 1280x800 design; root owns main.gd, project.godot, scenes/main.tscn and UI.

Simulation owns scripts/run.gd (class_name DefenseRun extends RefCounted) and scripts/loot.gd, scripts/sudoku.gd, tests/test_run.gd. No scene dependency. Public state: phase:String solve/prep/battle/loot/won/lost, round_no:int(1..50), max_rounds, mode(campaign/freeplay/locked), puzzle_difficulty, combat_difficulty(easy/medium/hard), seed_value:int, board:Array[int](81), solution:Array[int], givens:Array[bool], towers:Dictionary[int,Dictionary], enemies:Array[Dictionary], route:Array[Vector2] (coordinates col,row 0..8; can include entry/exit outside), recent_moves:Array[int], credits:int, fragments:int, health:float, max_health:float, score:int, timer:float, kills:int, spawned:int, spawn_total:int, items:Array[Dictionary], chests:Array[Dictionary], family_levels:Array[int](10), passives:Dictionary, active_effects:Array[Dictionary]. Constructor new_run(seed:int,options:Dictionary={}) explicitly called. Methods place(cell:int,number:int)->Dictionary, candidates(cell)->Array, hint(cell)->Dictionary, advance_phase()->Dictionary, next_round(options={}), update(dt), drain_events()->Array, tower_stats(cell)->Dictionary {damage,interval,range,level,effects}, upgrade_tower(cell), upgrade_family(number), equip_item(cell,item_id), unequip_item(cell,slot), use_item(item_id), open_chest(chest_id), buy_seed(number), buy_chest(rarity='common'), buy_passive(kind), spin_slots(), save_data()->Dictionary, load_data(data)->bool. Actions return {ok:bool,message:String,...}. phase progression is solve -> prep -> battle -> loot -> next_round; end battle automatic. Sudoku generation must be valid with unique solution, difficulty clue counts, use recent move routing. Correct placements earn currency; battle placements allow conflicts at credit cost and corruption consequences. Givens not towers. Towers dict {cell,number,level,attachments:Array,growth:float,cooldown:float,aim:Vector2}; enemies dict {id,pos:Vector2,hp,max_hp,progress,speed,kind,slow:float}; items {id,type,kind,name,rarity,power,description}; chests {id,rarity,cost}. Five slots. Save between rounds or full state with Vector2 conversion.

Events: type:String, cell:int optional, pos:Vector2 optional, target:Vector2 optional, color:Color optional, text:String optional, kind:String optional. Types plant,shot,hit,kill,leak,phase,loot,chest_open,upgrade,equip. Visual root consumes drain_events and calls board_renderer.play_event(event), audio.play_event(event). Preserve camera/model refs. Frequent updates do not emit UI notifications every frame.

Renderer owns scripts/board.gd class_name DefenseBoard extends Node3D, any scripts/voxel*.gd and shaders. setup(run), tick(dt), play_event(event), cell_at_screen(screen_pos)->int, set_selected(cell,number=0), set_reduced_motion(bool). Camera3D current. World coords: x=col-4, z=row-4, y up. 81 tiles; top-down solve readable number Label3D, eased tilted battle board transformation. Real voxel mesh towers with colored attachment layers, rotate towards enemies using aim or target, enemies, projectiles, route, particles and atmospheric environment. Avoid text full bright bloom. Public selected_cell:int. No UI inputs except methods; root owns input and panels. Root creates renderer and passes run. Numbers must stay clear throughout.

Audio owns scripts/sound.gd class_name DefenseSound extends Node; setup optional, play_event(event), click(), set_muted(bool), no external assets required; use generated AudioStreamWAV effects and ambient music if reasonable. Root adds node. Keep volume tame.
